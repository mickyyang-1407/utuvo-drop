# Artwork and media notes

Source code is provided under the repository's MIT license.

The cat atlas, tail sprite and presskit hero were generated with the built-in OpenAI
image generation tool, using the creator's existing cat artwork and actual Drop renders
as visual references. The hero is promotional illustration, not an application screenshot.
Its generation prompt is included in `docs/media/ARTWORK.md`.

App screenshots use synthetic sample files and an owned neutral background. Native file
icons shown within them are rendered by macOS. The application resolves system icons at
runtime; it does not bundle third-party icon libraries. Product and system names belong
to their respective owners. Do not imply endorsement by Apple or other third parties.
